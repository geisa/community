# GEISA Technical Notes

Technical notes, presentations, and implementation references developed in
support of GEISA architecture, demonstrations, and deployment discussions.

## Relationship to GEISA

This project contains community-maintained implementation guidance and
historical technical reference material related to GEISA.

The documents are supplemental and do not define the GEISA Specification,
establish conformance requirements, or replace current Specification
documentation.

## Project Information

- **Status:** Active
- **Maintainer:** Norm McEntire (@nmcentire400), original author
- **License:** CC0-1.0
- **GEISA versions tested or supported:** Document-specific; see each
  document's title and publication date
- **Support:** Best-effort

## Using the Documents

The documents may be viewed with any standard PDF reader.

Editable source documents were not present in the original repository at the
time of migration. They may be added later if the maintainer has suitable
source material available.

## Known Limitations

- The documents reflect the GEISA architecture and project state at their
  respective publication dates.
- Current Specification language and implementation guidance may have changed
  since publication.
- The PDFs are preserved with their original filenames and content.
- Inclusion in this repository does not make the documents normative or part
  of the GEISA conformance framework.
